# 🕵️ Reading Detective – Interactive Reading Comprehension Game

An interactive, Python-based reading comprehension game developed as part of the **Soft Skills LMS** project. The game helps students improve their reading comprehension, critical thinking, vocabulary, and analytical skills through engaging detective-style case investigations.

## 📌 Project Overview

**Reading Detective** is a desktop application built using Python and Tkinter. Players investigate different cases by reading passages, analyzing clues, and answering multiple-choice questions.

The game includes a scoring system, limited lives, instant feedback, and performance evaluation to make learning more interactive and enjoyable.

## ✨ Features

* 🕵️ **Interactive Case Investigations:** Solve reading-based detective cases.
* 📖 **Reading Comprehension:** Read passages and answer questions based on the information provided.
* 🔎 **Multiple Question Types:** Practice detail-based, inference-based, and vocabulary questions.
* 🎯 **Scoring System:** Earn 100 points for every correct answer.
* ❤️ **Lives System:** Start with three lives and lose one for each incorrect answer.
* ✅ **Instant Feedback:** Get immediate feedback and explanations after answering.
* 📊 **Performance Analysis:** View your score, correct answers, and accuracy percentage.
* 🎮 **Multiple Cases:** Progress through different cases with varying difficulty levels.
* 🎨 **Interactive GUI:** Enjoy a clean, dark-themed interface with separate reading and question panels.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project Folder

```bash
cd Reading-Detective
```

### 3. Check Python Installation

Make sure Python 3 is installed.

```bash
python --version
```

### 4. Run the Application

```bash
python reading_detective.py
```

**Note:** Tkinter is included with most standard Python installations. If it is missing, install the appropriate Tkinter package for your operating system.

## 🎮 How to Play

1. Launch the application.
2. Read the case description and the complete passage displayed in the **Case File** panel.
3. Review the question shown in the **Investigation** panel.
4. Select one of the four answer options.
5. Check the instant feedback and explanation.
6. Click **Next Question** to continue.
7. Complete the case or lose all three lives.
8. View your final score, accuracy, and performance feedback.
9. Select **Play Another Case** to start the next investigation.

## 🏆 Scoring and Performance

* **Correct answer:** +100 points
* **Incorrect answer:** Lose one life
* **Starting lives:** 3
* **Maximum score:** Depends on the number of questions in the case

### Performance Levels

| Accuracy   | Performance            |
| ---------- | ---------------------- |
| 80% – 100% | Excellent Detective 🏆 |
| 60% – 79%  | Good Investigation 🔎  |
| Below 60%  | Keep Practicing 📚     |
